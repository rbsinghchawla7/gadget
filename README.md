# Punjab Mobile Hub

GitHub/Vercel-ready React + Vite e-commerce starter.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in terminal.
3. Run `npm install`
4. Run `npm run dev`

## GitHub
Create a repository and upload all files in this folder.

## Vercel
Import the GitHub repository into Vercel. Vercel normally detects Vite automatically.
Build command: `npm run build`
Output directory: `dist`

## Important before launch
- Replace `WHATSAPP` in `src/App.jsx` with the real Punjab Mobile Hub WhatsApp number.
- Replace placeholder product images in `src/data/products.js` with your actual product image URLs.
- Update prices, descriptions, categories and stock data.
- Replace the placeholder policy wording with your final business-specific policies, shipping/return terms and legal/contact details.
- For a real production store, add a backend/database for orders, inventory and authentication.
